# Vertical Glow Portfolio

Este é um site de portfólio pessoal construído com tecnologias web modernas.

## Tecnologias Utilizadas

- **Vite** (ferramenta de build e dev server)
- **React 18**
- **TypeScript**
- **Tailwind CSS** (utilitário de estilos)
- **shadcn/ui** (componentes UI baseados em Radix UI)
- **Radix UI** (acessibilidade e componentes)
- **Supabase** (backend as a service)
- **React Router DOM** (roteamento)
- **React Hook Form** (formulários)
- **Zod** (validação)
- **TanStack React Query** (data fetching)
- **Vite Plugin React**
- **Outros:** date-fns, lucide-react, embla-carousel, recharts, clsx, etc.

## Como Executar o Projeto

### Pré-requisitos
- Node.js 20.x ou superior
- npm 9.x ou superior

### Passos para rodar localmente

1. **Clone o repositório:**
   ```sh
   git clone <YOUR_GIT_URL>
   ```

2. **Acesse o diretório do projeto:**
   ```sh
   cd vertical-glow-portfolio-main/vertical-glow-portfolio-main
   ```

3. **Instale as dependências:**
   ```sh
   npm install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```sh
   npm run dev
   ```

O site estará disponível em `http://localhost:8080` (ou porta informada no terminal).

### Observações
- Se ocorrer erro relacionado ao Rollup ou SWC, apague a pasta `node_modules` e o arquivo `package-lock.json` e rode `npm install` novamente.
- O projeto utiliza Vite, então o recarregamento é instantâneo.
- Para builds de produção, use `npm run build`.
