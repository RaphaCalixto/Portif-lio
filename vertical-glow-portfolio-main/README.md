# Vertical Glow Portfolio

Este é um site de portfólio pessoal construído com tecnologias web modernas.

## Tecnologias Utilizadas

Este projeto foi construído com:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## Como Executar

Siga estes passos para rodar o projeto localmente:

### Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/) e npm instalados. É recomendado usar o [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

### Instalação

1.  **Clone o repositório:**
    ```sh
    git clone <YOUR_GIT_URL>
    ```

2.  **Navegue até o diretório do projeto:**
    ```sh
    cd vertical-glow-portfolio
    ```

3.  **Instale as dependências:**
    ```sh
    npm i
    ```

4.  **Inicie o servidor de desenvolvimento:**
    O servidor iniciará com recarregamento automático e uma prévia instantânea.
    ```sh
    npm run dev
    ```
